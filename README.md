# Projet PROG6 2024-25

## JEU : Onitama

Onitama est un jeu où deux joueurs s'affrontent avec 5 pions chacuns, 1 pion Maitre et 4 pions Eleves sur un plateau de 5x5 cases.
Chaque Joueur possède 2 cartes tirées aléatoirement au début de la partie.
Une carte supplémentaire qui sera échangée avec la dernière carte jouée à chaque tour est également présente sur le plateau.
Les pions de tous types peuvent se déplacer conformément aux déplacements indiqués sur les cartes, la case noire indique la position du pion qu'on souhaite déplacer.
Tous les déplacements sur la carte sont valides à condition de ne pas écraser ses propres pions ou sortir du terrain.
Pour gagner, il faut prendre le pion maitre de l'adversaire ou placer son propre pion maitre à l'entrée du temple adverse (position initiale du pion maitre adverse en début de partie).

## Développement

Intellij recommandé

```sh
mvn install
```

puis

utiliser la cible proche du bouton play vert (la cible affiche "Onitama" ou "All in PROG6-PROJET-2024-25")

ou

clic droit sur le dossier tests > Run all tests
